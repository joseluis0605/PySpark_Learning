# PySpark_Learning
Repositorio de código sobre un curso de Pyspark

Para clonar repositorio:
1. git init // para iniciar git
2. git remote add <nombre_url> <url_repositorio> // conectamos al repositorio
3. git branch -M main // nos situamos sobre la rama que queramos
  

Chuleta básica
1. git add <fichero> // añadir fichero para subir a repositorio
2. git commit -m "mensaje de commit" // hacemos commit para subir fichero + comentario
3. git push -u origin main // hacer push del fichero
